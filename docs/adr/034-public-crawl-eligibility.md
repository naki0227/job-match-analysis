# ADR-034: 公開ページのrobots判定で取得対象を決める

## 背景・課題

ADR-026はサイトごとの利用条件確認を必須としていた。これでは確認済みサイトがない間、任意の公開求人URLを解析できない。ローカルMVPの取得対象を決める必要があった。

## 選択肢

1. 手動確認済みドメインだけを許可する。サイトごとの判断を記録できるが、対応範囲は限定される。
2. 公開URLについてrobotsが許可する場合に取得する。対応範囲は広いが、robotsだけで利用条件上の許諾まで確認できるわけではない。

## 決定と理由

利用者の選択により2を採用する。Crawlerは公開HTTPS、DNS全回答・接続先IP固定・redirectとブラウザ要求の検査をADR-021に従って行い、各originのrobotsが許可するpathだけ取得する。robots取得不能・禁止時は保留する。追加のサイト遮断が必要なら呼び出し側の`siteAllowed`で制限できるが、手動承認リストは必須にしない。

## メリット・デメリット・見直し条件

任意の公開求人URLを処理対象にできる。robotsはサイトの利用規約や二次利用許諾を代替しないため、対象サイトからの拒否、利用条件の変更、引用・保持上の問題が判明したら当該サイトを遮断し、取得方式を見直す。取得頻度・ジョブ上限・ネットワーク層egressは運用段階で決める。
