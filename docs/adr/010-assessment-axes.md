# ADR-010: MVPで8つの就業価値観軸を使う

## 背景と課題

Issue #11で本人への質問と、公開された企業・求人資料を評価する基準が必要になった。少数の軸だけでは希望を十分に表せず、軸を増やすと入力負担と根拠不足が増える。

## 選択肢

- 5軸: 働く場所・裁量・協働・成長の方向・仕事の変化。
- 8軸: 上記に勤務時間の柔軟性・役割の幅・顧客との接点を追加。
- 上限なしで軸を追加: 表現力は増すが、個々の質問・公開情報のルーブリック・版管理が追いつかない。

## 採用した案と理由

ユーザーの判断により8軸を採用する。追加した3軸は既存の5軸と異なる希望を表し、公開された勤務条件や職務内容に明示される可能性がある。各軸の意味と0/50/100アンカーは[評価軸の仕様](../assessment-axes.md)に記す。

## メリット

- 働く場所と勤務時間、成長の方向と役割の幅など、異なる希望を別々に表せる。
- 軸ごとに出典を確認し、情報不足を明示できる。

## デメリット

- 8つの希望と重要度を入力する負担がある。
- 公開資料に明示されない軸では `unknown` が増える。
- 質問・評価基準を変える際には軸の版管理が必要になる。

## 見直し条件

入力途中の離脱、軸ごとの `unknown` 率、利用者からの混同や不足の報告を確認する。軸を追加・変更するときは既存版を上書きせず、新しい版としてレビューする。
